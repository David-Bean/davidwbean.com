The lookup table is the only place numbers live. Bars, chips and the per-kid tables are all derived from it, so editing one point value rescales every chart at once. The penalties and the two scored activities are seeded from the note itself (−10 fighting, −10 pushing, −10 arguing, −5 for the wax wizard, swim race 50, head under water 15). The note put no value on any sighting, so every sighting starts at 1 point per animal — a bar is a count until you say otherwise. Clear a value and it stops counting: that row draws as a stripe and reads “no points set” on hover, which is how the five things the note never scored (annoying, false spotting, tattling, pestering, lying) appear now. One caveat: a value here applies to every entry of that type, so scoring arguing scores Luke's argument too, and scoring fighting scores all three of Kolvin's fights, not just the one the note priced. Edits save in this browser only — keep the JSON block above if you want them anywhere else.
